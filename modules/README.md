# modules

Contextos delimitados em arquitetura hexagonal: `domain/`, `application/`, `infra/` e `index.ts` (única API pública). Crie módulos com `pnpm gen:module <nome>`; nunca à mão. Módulos previstos: identidade, cadastro, calendario, prazos, captura, publicacoes, classificacao, notificacoes, ciencia, auditoria, busca, relatorios, administracao.

Implementado em: HU04 (gerador) e histórias de cada módulo. Siga o [CLAUDE.md](/CLAUDE.md) e a página Arquitetura do PrejuZero.
