# apps/mcp

Servidor MCP (Model Context Protocol) do PrejuZero (ADR-016): expõe o catálogo de ferramentas de IA a assistentes externos, com autenticação OAuth 2.1, escopos do catálogo de permissões, tenant aplicado no código e auditoria de cada chamada. Ferramentas que alteram estado exigem confirmação humana.

Implementado em: HU60 (F2). Siga o [CLAUDE.md](/CLAUDE.md) e os ADRs citados.
